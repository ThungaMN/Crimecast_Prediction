# CrimeCast: Crime Category Prediction Model

This project aims to build a machine learning model that predicts the category of a crime based on historical crime record.

## 🔧 Tools Used
- Python
- Pandas, NumPy
- Scikit-learn
- GradientBoostingClassifier

## 📊 Accuracy
Achieved 88.13% model accuracy.

## 📁 Files Included
- crimecast_model.ipynb
- data_cleaning.py
- final_model.pkl

## 💡 Learnings
- Feature engineering for categorical data
- Model evaluation using confusion matrix and F1 score
- Hyperparameter tuning
